# SaaS Customer Data Cleaning Pipeline

## 📌 Overview

A Python-based project that demonstrates **data cleaning, validation, customer analysis, and file handling** using a SaaS customer dataset.

## 🎯 Objectives

* Clean and validate customer data
* Handle missing and invalid values
* Remove duplicate records
* Standardize date formats
* Add and manage customer records
* Identify low-usage customers
* Generate summary statistics
* Export cleaned data to CSV

## 🛠️ Technologies

* Python
* Functions & Loops
* Object-Oriented Programming
* Exception Handling
* `datetime`
* `csv`

## 🔄 Key Steps

**Raw Data → Data Validation → Data Cleaning → Analysis → Export**

The project handles missing names, invalid monthly fees, missing usage hours, inconsistent dates, and other data-quality issues.

## 📊 Key Results

* **Total Customers:** 9
* **Average Monthly Fee:** 52.49
* **Total Usage Hours:** 748
* Identified customers with **less than 50 usage hours**.

## 📁 Output Files

* `saas_customers_cleaned.csv`
* `plan_summary.txt`
